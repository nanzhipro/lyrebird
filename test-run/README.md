# test-run/ — 用 resume.md 端到端跑测试评估的产物

## 目的

这个目录里的产物**不是真实候选人对话**,而是基于 `../resume.redacted.md`(候选人原型为一份 20+ 年 Apple 端架构经验的虚构简历)和虚构补充叙事,演示 Skill 在金标准用例 `GC-001`(见 `../cognitive-mechanism-extractor/evals/golden-cases.md`)下的产物形态。

虚构叙事的部分**已在每份文件首段明确声明**,并在每条具体事件 quote 末尾用 `[虚构补充]` 标注,**不能**被误认为是候选人的真实陈述。

## 文件清单

| # | 文件 | 对应阶段 | 演示什么 |
|---|---|---|---|
| 1 | `01-hypothesis-map.md` | 阶段 2 | 简历假设地图,包含 6 个假设与 4 个待挖事件 |
| 2 | `02-evidence-cards.md` | 阶段 3 | 6 张 evidence cards(覆盖 3 个事件)+ 2 张反证 |
| 3 | `03-mechanism-cards.md` | 阶段 5 | 1 张 validated + 2 张 strong-hypothesis 机制卡 |
| 4 | `04-final-report.md` | 阶段 6 | 完整最终报告 |
| 5 | `EVAL.md` | 全部 | 对照 evals/ 的自评结论与 PASS/FAIL 记录 |

## 评估目标

- 验证 Skill 的 4 阶段产物在文件结构、字段、回指、命名、置信度上**结构合规**。
- 验证 Skill 在虚构候选人输入下能**不越界**(不出现招聘判定、人格标签、伪造量化)。
- 揭示 Skill 在产品化前还需要的改进点。

## 重要声明

- **本目录的产物不是对任何真实候选人的评价**。
- 真实跑本 Skill 时,候选人会用自己的话回答,产物会与本目录显著不同。
- 本目录仅用于 **结构验证 + 回归测试基线**。
