# 简历改写模板

> 本模板把简历从"做了什么"改写为"如何思考/判断/推进"。每条改写都必须能回指至少一个机制(M-00X)或证据(E-00X)。
> **绝对禁止伪造量化指标**。候选人没有亲口说出来的数字,改写后保留"未量化"。

## 1. 改写原则

| 原则 | 反例 | 正例 |
|---|---|---|
| 用判断动词替代执行动词 | "负责 X" | "在 Y 约束下,通过 Z 方式权衡 A 与 B,推进 X" |
| 暴露关键判断点 | "完成 0 到 1 落地" | "在需求边界未定、依赖方未对齐时,先锁住 3 个成败变量再推进,完成 0 到 1 落地" |
| 显示边界条件 | "擅长跨部门协调" | "在责任边界未定的项目中,先识别关键约束并组织小范围共识,再推进跨部门协作" |
| 保留候选人原量化 | "提升 30%(候选人没说过)" | "提升 _%(候选人未量化)" 或 "显著降低 X(未量化)" |
| 单条不超过 2 行 | 5 行长描述 | 1-2 行 + 紧凑句式 |

## 2. 公式

`[情境约束] + [候选人的关键判断动作] + [外显行为] + [产生的价值(若有量化保留量化,否则定性描述)]`

## 3. 改写示例三档

### 版本一: 面向通用岗位(强调跨场景适用性)

> 原句: "[填入简历原句]"
>
> 改写:
> "[情境约束],我先通过[判断动作 X]锁定[成败变量 Y/Z/...],再[外显行为],降低[风险类型]。"
>
> 改写依据: 机制 M-00X([名称]),证据 E-00X。

### 版本二: 面向管理/协调型岗位(强调协调与边界拿捏)

> 原句: "[填入简历原句]"
>
> 改写:
> "在[多方约束/边界未定]的场景下,先[识别动作],再以[沟通策略]推进[利益相关方]达成最小共识。"
>
> 改写依据: 机制 M-00X([名称]),证据 E-00X。

### 版本三: 面向高模糊问题解决型岗位(强调拆题与抽象)

> 原句: "[填入简历原句]"
>
> 改写:
> "在[目标不清/约束分散]的场景下,通过[拆解动作]把[模糊问题]还原为[3-4 个可决策项],再迭代推进。"
>
> 改写依据: 机制 M-00X([名称]),证据 E-00X。

## 4. 自检清单(每条改写都过一遍)

- [ ] 这句话能回指到至少一个 mechanism_id 或 evidence_id 吗?
- [ ] 我有没有添加候选人没说过的数字、百分比、人数、时间?
- [ ] 这句话还像简历语句吗(不要写成机制卡的长说明)?
- [ ] 这句话保留了候选人的原始约束与情境吗?
- [ ] 这句话避免了"高度负责""有 owner 意识""综合能力强"这类空话吗?

## 5. 候选人确认环节

每条改写,**必须**向候选人逐条问:
- "这句话还像你做的事吗?"
- "如果是,我们保留;如果有 1 个词不对,你想改成什么?"

候选人否决的句子不进入最终报告。
