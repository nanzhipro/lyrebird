# 触发测试 (trigger-tests)

> 验证 Skill 是否在正确场景被启动,在错误场景不启动。
> 这些 case 用于人工评审与回归测试,不在运行时执行。

## 测试矩阵

| # | 用户输入 | 期望 | 验证点 |
|---|---|---|---|
| T-01 | "帮我萃取一下我的认知机制,我准备好简历了" | ✅ 触发 | 明确意图 + 提供简历 |
| T-02 | "我想做一次深度自我访谈,把我的工作判断模式挖出来" | ✅ 触发 | 明确深度访谈意图 |
| T-03 | "我有简历,想看看我背后的思维模式" | ✅ 触发 | 暗示深度,需 AI 确认 |
| T-04 | "帮我润色简历" | ❌ 不触发 | 简历润色 ≠ 机制萃取 |
| T-05 | "帮我把简历翻译成英文" | ❌ 不触发 | 翻译 |

## 触发判定逻辑

`disable-model-invocation: true` 意味着 AI 不会自动调用本 Skill。
触发依赖以下任一:

1. 用户明确说出"认知机制萃取"、"深度自我访谈"、"挖判断模式"等关键词。
2. 用户输入了 Skill 名称或路径 `cognitive-mechanism-extractor`。
3. 用户上传了简历并明确要求"深度萃取"而非"润色/翻译/匹配"。

## 模糊情况的处理

| 输入 | AI 应做 |
|---|---|
| "我想了解自己一下,有什么工具适合" | 不直接触发,先问候选人具体目标:深度认知萃取 / 简历优化 / 职业规划 / 人格测试 / 心理咨询?根据答案推荐对应 Skill 或拒绝 |
| "你能帮我看看我的简历吗" | 不直接触发,先问"你想要什么样的看法:格式润色、深度萃取背后思维模式、还是岗位匹配?" |
| "我做了 10 年开发,想总结一下自己" | 不直接触发,先确认是"写自传" / "做演讲" / "深度萃取认知机制" |

## 反向触发(主动告知不适用)

候选人输入以下内容时,AI 应**主动告知本 Skill 不适用**并解释边界:

| 输入 | 应答 |
|---|---|
| "我现在很焦虑,工作出问题,我想知道我是不是有抑郁" | "这超出了本 Skill 的边界,我们不做心理健康诊断。建议你寻找专业心理咨询。如果你只是想萃取工作中的认知机制,我们可以做。" |
| "你帮我评估一下我能不能进字节" | "我们不做招聘评估。我能帮你显性化你的工作认知机制,但不预测你能否进某个公司。" |
| "我想测一下我的智商" | "我们不做 IQ 评估。" |

## 测试通过标准

| 指标 | 标准 |
|---|---|
| 正确触发率 | T-01/02/03/11/12 全部触发 |
| 错误触发率 | T-04/05/06/07/08/09 全部不触发 |
| 模糊澄清率 | T-10 触发澄清流程 |
| 反向告知率 | 心理/招聘/IQ 越界输入,100% 告知边界 |

## 回归测试

每次升版 Skill 后,需要复跑上述 12 个 case,并新增至少 2 个新 case。
