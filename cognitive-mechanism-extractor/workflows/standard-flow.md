# 标准流程 (standard-flow)

> 完整版流程,5-7 轮,产出 3-4 张机制卡 + 完整报告 + 后续访谈计划。
> 适合已经跑过 MVP、想做更深萃取的候选人,或在企业内部用于关键岗位人员的发展辅导。

## 与 MVP 的差异

| 维度 | MVP | 标准流程 |
|---|---|---|
| 轮次 | 3-4 轮 | 5-7 轮 |
| 事件数 | 2 个 | 3-4 个 |
| 机制数 | 2-3 个 | 3-4 个 |
| 反证深度 | 候选人讲 1 个反例 | 每个机制 ≥ 1 反例 + AI 提示 3 个失效假说 |
| 迁移测试 | 1 轮 | 2 轮(资源迁移 + 跨领域迁移) |
| 报告厚度 | 标准报告 | 标准报告 + 下一轮访谈计划 + 长期发展路径建议 |
| 候选人共创 | 命名时 | 命名 + 简历改写 + 面试表达 全部共创 |

## 流程概览

| 轮 | 阶段 | 目标 |
|---|---|---|
| 1 | 契约 + 假设地图 | 5-10 个假设 + 4-6 个待挖事件 |
| 2 | 第 1 事件深描 | 3 张 evidence |
| 3 | 第 2 事件深描 | 3 张 evidence,跨事件初聚类 |
| 4 | 第 3 事件深描 + 跨事件归并 | 3 张 evidence + 3-4 个 mechanism_drafts |
| 5 | 命名 + 反证 | 3-4 张 mechanism cards |
| 6 | 简历改写 + 面试表达 共创 | 9 条改写候选 + 3 种面试版本 |
| 7 | 报告输出 + 候选人最终修订 | 最终报告 + 下一轮访谈计划 |

## 与 MVP 的关键加强点

### 1. 假设地图更厚

阶段 2 多挖 2-3 个假设(主要是从 "缺口" 与 "自评" 类拉的),增加待验证空间。

### 2. 跨事件证据三角验证

每个候选机制必须由 **≥ 3 个不同情境** 的事件支持(MVP 是 2 个)。

### 3. 双轮迁移测试

每个机制做 2 次迁移测试,一次资源迁移,一次跨领域迁移。

### 4. AI 提示 3 个失效假说

候选人未主动讲反例时,AI 主动给 3 个常见失效假说,详见 [question-bank/contradiction-probes.md](../question-bank/contradiction-probes.md)。

### 5. 简历改写共创

不只是 AI 生成 → 候选人确认,而是:
1. AI 给 2 个改写候选。
2. 候选人挑 / 改 / 推翻。
3. 候选人复述确认。
4. 进入最终版本。

### 6. 下一轮访谈计划

报告最后增加 "下一轮访谈主题建议",列出:
- 哪个 strong-hypothesis 优先升级为 validated?
- 哪个 weak-signal 优先补证?
- 哪类事件还没覆盖?

## 标准流程成功标准

| 指标 | 标准 |
|---|---|
| 轮次 | 5-7 轮 |
| validated 机制数 | ≥ 2 张 |
| 总机制数 | 3-4 张 |
| 候选人对 validated 机制的识别度 | 平均 ≥ 0.85 |
| 每个 validated 机制反证证据 | ≥ 1 张 counterevidence |
| 报告附"下一轮访谈计划" | ✓ |

## 何时切回 MVP

- 候选人时间不足,愿意只做 2-3 个机制 → 切回 [mvp-flow.md](mvp-flow.md)
- 候选人投入度低 → 切到 [low-engagement-recovery.md](low-engagement-recovery.md)
