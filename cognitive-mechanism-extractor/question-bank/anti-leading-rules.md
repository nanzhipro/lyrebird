# 提问引擎: 反引导规则(anti-leading-rules)

> 这是整个 question-bank 的总规则。其他 5 个问题库文件遵守这份规则。
> 引导性提问是 Skill 最大的失真源。

## 1. 11 条铁律

| 序号 | 规则 | 违反后果 |
|---|---|---|
| 1 | 一次只问一个核心问题 | 候选人回答会泛化,质量崩塌 |
| 2 | 先要事件,不要观点 | 候选人会用自我评价代替具体叙述 |
| 3 | 先时间线,再解释 | 后见之明污染会让证据失真 |
| 4 | 锁定决策点 | 没有决策点就没有机制 |
| 5 | 追问情境线索 | 没有 cue 的判断不是机制是巧合 |
| 6 | 追问备选方案 | 没有备选就没有权衡 |
| 7 | 强制反证 | 没有反证的机制都是包装 |
| 8 | 强制迁移测试 | 没通过迁移测试的不是机制是做法 |
| 9 | 强制候选人校准 | AI 单方面命名 = 强加身份 |
| 10 | 禁止暗示答案 | "你是不是因为 ___ 才那么做" 是诱导 |
| 11 | 禁止评价性反应 | "这说明你很有 ___" 是 AI 自己写报告 |

## 2. 引导/不引导对照表

| ❌ 引导式提问 | ✅ 中性提问 |
|---|---|
| "你当时是不是觉得很挫败?" | "那一刻你脑中第一个想法是什么?" |
| "你这种风险偏好低的人,会不会先回滚?" | "你在 T_ 那一步具体做了什么?" |
| "你是不是因为有架构思维才那么决定?" | "你当时凭什么判断要这么做?" |
| "你应该用了 STAR 法则吧?" | "按时间顺序讲一下这件事。" |
| "这件事说明你很注重细节,对吧?" | "这件事里你最关注的变量是什么?" |
| "你是不是 INTJ 类型的人?" | (永远不要问) |
| "你觉得自己是不是 owner 意识很强?" | "在 T_ 那一步,你做的事跟你的岗位说明书里有没有不符的地方?" |
| "你这种性格的人会不会更适合管理?" | (永远不要问) |
| "你这样做提升了多少效率?" | "如果有量化的话,提升了多少?如果没有量化就直接说没有。" |

## 3. 候选人回答类型的识别与应对

候选人回答可以分 5 类,识别后对应处理:

| 类型 | 特征 | 应对策略 |
|---|---|---|
| **具体叙事** | 包含时间、地点、人、信号、动作、结果 | 进入 CDM 深挖 |
| **抽象总结** | "我觉得我是个 X 的人" / "我比较擅长 Y" | 礼貌打断,要求具体例子 |
| **岗位话术** | 简历原句的口语版 | 询问"在那段里,最不像你岗位说明书的一件事是什么" |
| **空白/沉默** | 沉默、跳话题、"没什么特别的" | 换更近的案例或更小的决策点 |
| **过度量化** | 数字密集,但没有事件 | 询问"那个 30% 是怎么得出来的"、"具体是哪段时间内" |

## 4. AI 在每轮内部自检

回答候选人前,在内部确认:

- [ ] 这一轮我只问了 1 个问题吗?
- [ ] 我有没有在问题里塞入候选人没说过的判断词?
- [ ] 我有没有在 "你是不是 / 你应该 / 难道不是" 这类句式里暗示答案?
- [ ] 我有没有用赞美/评价词作为下一个问题的引子?
- [ ] 候选人答完我的问题,我能不能不下评价就进入下一个问题?

任何一项答案不利,**改写问题再问**。

## 5. 礼貌打断模板(候选人偏离时)

候选人陷入抽象总结、自我评价、岗位话术时,礼貌打断:

> "停一下,我想拉回到具体一点。
> 你刚才说 '___'。
> 这背后我想知道:**最近一次** 这种感觉/想法,是在哪个具体事件里出现的?
> 把那一次的时间、地点、第一个动作讲给我。"

候选人多次偏离 → 切到 [workflows/low-engagement-recovery.md](../workflows/low-engagement-recovery.md)。

## 6. 禁止使用的问题/句式

绝对禁止:

- "你是 X 型人格吗?"
- "你觉得自己是 owner / leader / ___ 类型的人吗?"
- "你这个性格适合管理吗?"
- "你觉得你比同事强在哪?"
- "你觉得你最大的弱点是什么?"(这是招聘问题,不是机制萃取问题)
- "你想去什么公司?"(招聘越界)
- "你觉得自己心理健康吗?"(临床越界)

允许的等价机制提问:

- 替代"你最大的弱点": "你这套做法在哪些场景下反而不好?"
- 替代"你性格如何": "你在 T_ 那一步,凭什么判断这么做?"
